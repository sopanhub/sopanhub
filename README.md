## 🛠️ Featured Projects

### 🌐 [PiglixMCMods.dev](https://www.piglixmcmods.dev): Full-Stack Platform
A production web platform for Minecraft shaders, texture packs and mods, built and maintained solo, serving **61k+ users**.

- **Redis-backed rate limiter** (120 requests/min per IP) that stays consistent across serverless instances
- **Quota guard + caching layer** that caps CurseForge calls at 5,000 per hour to stay within third-party API limits
- **REST API routes** for search, likes, downloads and stats
- **Firestore security rules** so users can only edit their own comments

`Next.js` `Firebase / Firestore` `Redis` `Vercel`

---

### 🤖 [TubeMationAI](https://github.com/sopanhub/TubeMationAI): AI YouTube Shorts Automation Engine *(Open Source)*
An end-to-end pipeline that turns a long-form video URL into a **published YouTube Short with no manual steps**.

- **Gemini** picks the most engaging transcript segment and writes a short voiceover hook
- **Face tracking** (MediaPipe + OpenCV) for a smooth 9:16 crop
- **Whisper** word-level captions rendered with FFmpeg
- **Next.js frontend + Python backend**, with the final YouTube upload automated

`Next.js` `Python` `Gemini` `OpenCV` `MediaPipe` `Whisper` `FFmpeg`
